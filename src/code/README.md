# 代码结构说明

本目录包含插件的核心代码实现，采用模块化设计，每个文件负责特定的功能。

## 文件说明

### componentGenerator.ts

组件生成器，是整个插件的核心协调器，主要功能：

- 协调整个组件生成流程
- 调用模板管理器和用户界面模块
- 处理初始路径参数（支持右键菜单点击文件夹时自动使用该路径）
- 处理组件生成过程中的错误

### templateManager.ts

模板管理器，负责模板的处理，主要功能：

- 提供可用模板选项
- 读取模板文件内容
- 替换模板中的变量（如组件名）
- 将处理后的内容写入目标文件

### userInterface.ts

用户界面处理，负责所有与用户的交互，主要功能：

- 获取用户输入的组件名称
- 提供模板类型选择界面
- 处理保存路径的选择和确认
- 显示成功/错误消息
- 打开新创建的文件

## 模块间关系

```
extension.ts
    │
    ├── 创建 TemplateManager 实例
    │       │
    │       └── 负责模板文件处理
    │
    ├── 创建 UserInterface 实例
    │       │
    │       └── 负责用户交互
    │
    └── 创建 ComponentGenerator 实例
            │
            └── 协调生成流程
```

## 扩展指南

如需添加新的模板类型，请按照以下步骤：

1. 在 `src/template/` 目录添加新的模板文件
2. 更新 `templateManager.ts` 中的 `TemplateType` 类型和 `getTemplateOptions()` 方法
3. 确保模板中有可替换的组件名称标识
